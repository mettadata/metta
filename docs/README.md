# metta documentation

**metta** is a composable, spec-driven development framework for AI-native software engineering — a CLI/dev tool that orchestrates the full change lifecycle (propose → plan → execute → verify → finalize → ship). It works with any AI coding tool via *instruction mode*: metta manages state and specs while the AI tool does the work.

This page maps the documentation by audience. Start with **Getting Started** if you're new.
