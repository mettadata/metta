## Batch 1 (no dependencies)

- [x] **Task 1.1: RoadmapStore lifecycle surface — `remove`, `removeSlugs`, `retire`; delete `removeTop`; store unit tests**
  - **Files**: `src/roadmap/roadmap-store.ts`, `tests/roadmap-store.test.ts`
  - **Action**:
    - Extend the `RoadmapValidationError` discriminator union to `'duplicate_entry' | 'invalid_reorder' | 'not_found'` — no new error class (ADR-2). Distinct miss messages: position miss `No roadmap entry at position N (roadmap has M entries)`; slug miss `No roadmap entry with slug '<slug>'`.
    - Add private `spliceAndSave(entries, indices: ReadonlySet<number>): Promise<RoadmapEntry[]>` — filters out entries at `indices`, persists via the existing canonical `save()` (→ `RoadmapSchema.parse` → `formatRoadmap`), returns removed entries in roadmap order. All three new mutators flow through it (design "One write path").
    - Add `async remove(target: string | number): Promise<{ entry: RoadmapEntry; position: number }>` — `load()`; `typeof target === 'number'` → bounds-check `target - 1` against `0..length-1`, string → `findIndex` on slug; miss throws `RoadmapValidationError('not_found', ...)` with the file untouched; hit → `spliceAndSave` → `{ entry, position: index + 1 }`. Do NOT call `assertSafeSlug` on the string branch (design §API 1: never writes the target or builds a path from it).
    - Add `async removeSlugs(slugs: string[]): Promise<RoadmapEntry[]>` — `load()`; empty input → return `[]` with no write; build the index set from a slug `Set`; any input slug matching zero entries → typed `not_found`, file untouched (defensive concurrent-write contract); single load/validate/save (ADR-4); returns removed entries in roadmap order.
    - Add `async retire(slug: string): Promise<RoadmapEntry[]>` — no-throw for expected cases (ADR-6): removes ALL entries matching `slug` (duplicate-tolerant, exact case-sensitive equality on `entry.slug`); no match (including absent `spec/roadmap.md`) → return `[]` with no write and no file creation; else `spliceAndSave`.
    - **Delete `removeTop`** and its describe block in the test file (currently lines 167–180) — sole production caller is the old `next` handler, removed in Task 2.1 (ADR-4).
    - Add store tests S1–S14 per the design test matrix: `remove` by position/slug with canonical renumber and verbatim note preservation, only-entry → header-only file `# Roadmap\n\n`, out-of-range positions (`0`, `length+1`) and absent slug → typed `not_found` with byte-for-byte unchanged file, missing file → `not_found` without file creation; `removeSlugs` middle entry, multi-slug single-write with roadmap-order return, unknown slug → `not_found` untouched, `[]` no-op; `retire` match, hand-written duplicates all removed, no-match `[]` byte-identical, missing file `[]` still absent.
  - **Verify**: `npx vitest run tests/roadmap-store.test.ts` passes; `npx tsc --noEmit` clean except errors localized to `src/cli/commands/roadmap.ts` if the compiler reaches the now-missing `removeTop` call (fixed in 2.1 — run `npx vitest run tests/roadmap-store.test.ts` as the gate for this task).
  - **Done**: Public mutation surface is exactly `add`, `reorder`, `remove`, `removeSlugs`, `retire`; `removeTop` absent from source and tests; all S1–S14 cases green; every write path flows through `spliceAndSave` → `save()`.
