# Follow-ups from the backlog/milestones rework review (PR #85): stale spec/backlog references, dual issues-store tests, directory-wide auto-commit staging, ANSI passthrough in list renderers, guard-bash bare backlog allowlist gap, tier advisory recommends unsupported full upscale

**Captured**: 2026-08-16
**Status**: logged
**Severity**: minor

## Symptom
Review of the backlog/milestones rework (PR #85, archived 2026-08-16) plus a live zeus session the same day surfaced six residual defects that survived the merge: (1) stale references to the removed `spec/backlog/` store remain in docs and in `refresh.ts`, so regenerated CLAUDE.md still advertises the dead directory; (2) two issues-store test files exist side by side (`src/issues/issues-store.test.ts` and `tests/issues-store.test.ts`), with the `src/` copy even compiling into `dist/`; (3) backlog auto-commit stages the whole `spec/issues` directory instead of the explicit files it wrote; (4) issue titles are printed raw in the new list renderers, so ANSI escape sequences in frontmatter pass through to the terminal; (5) bare `metta backlog` is blocked by the guard-bash hook as an unknown subcommand even though it is a read-only view (hit live in zeus, which also blocked `backlog list --json` on its older shipped hook copy); (6) the tier advisory rendered "scored full -- upscale recommended" although upscale-to-full is unsupported, a pre-existing gap now hit twice.

## Root Cause Analysis
The rework moved the backlog from a directory store to a frontmatter view over `spec/issues/`, but the sweep was incomplete at the edges. `refresh.ts:176` still emits the `spec/backlog/` Table-of-Contents row into every regenerated CLAUDE.md, and `docs/workflows/README.md`, `docs/workflows/skills.md`, `docs/internals/architecture.md`, `docs/guide/troubleshooting.md`, `docs/internals/guard-hooks.md`, and `src/templates/hooks/metta-guard-edit.mjs:130` still describe or allowlist the removed directory. The test consolidation was missed because the rework added `src/issues/issues-store.test.ts` colocated with the source while the repo convention keeps tests under `tests/` (near 1:1 ratio); both files now exist and the colocated one ships in `dist/`. `commitPaths` in `src/cli/commands/backlog.ts` is called with the directory pathspec `join('spec','issues')` at three sites (lines 181, 267, 304), so any unrelated dirty file under `spec/issues/` is swept into the auto-commit. The list renderers print `e.title` / `issue.title` verbatim (`backlog.ts:75`, `milestone.ts:176`) with no control-character stripping, giving frontmatter-supplied ANSI a path to the terminal. In the guard hook, `backlog` was added to `ALLOWED_TWO_WORD` (`list`, `show`) but never to `ALLOWED_BARE`, so the bare read-only form fails closed unlike `roadmap`/`release`; zeus additionally runs a stale shipped hook copy predating the two-word entry. Finally, `src/complexity/renderer.ts:48` renders the generic "upscale recommended" advisory for any higher-scored tier; `complete.ts` caps the full-tier path in two places (lines 362-367, 462-466) but the cap is not applied everywhere the renderer output surfaces, and full-tier upscale remains unwired even though `src/templates/workflows/full.yaml` exists — the decision (support full upscale vs. cap the advisory at standard globally) was never made.

### Evidence
- `src/cli/commands/refresh.ts:176` — still pushes the `| [Backlog](spec/backlog/) | ... |` row into regenerated CLAUDE.md after the store was removed.
- `src/cli/commands/backlog.ts:181` — `commitPaths(ctx.projectRoot, [join('spec', 'issues')], ...)` stages the whole directory rather than the explicit files the command wrote (same pattern at lines 267 and 304).
- `src/templates/hooks/metta-guard-bash.mjs:77` — `ALLOWED_BARE = new Set(['roadmap', 'release'])` omits `backlog`, so bare `metta backlog` classifies as unknown and fails closed despite being a read-only view.

## Candidate Solutions
1. **Single hardening pass (recommended)** — One change that: sweeps all stale `spec/backlog/` references (refresh.ts, the five docs, guard-edit template); deletes `src/issues/issues-store.test.ts` after folding any unique cases into `tests/issues-store.test.ts`; narrows `commitPaths` call sites to explicit file paths; strips ANSI/control characters from titles in the backlog and milestone list renderers; adds `backlog` to `ALLOWED_BARE` in both hook copies (repo `.claude/hooks/` and `src/templates/hooks/`); and caps the tier advisory at standard wherever the renderer output surfaces. Tradeoff: bundles six concerns into one change, so review granularity and bisectability suffer if one fix regresses.
2. **Split into per-item quick fixes** — Log each item through `/metta-quick` (or `/metta-fix-issues` per slug) so every fix ships atomically with its own verification. Tradeoff: six lifecycle passes of overhead for mostly one-file edits, and the zeus-facing guard fix waits behind queue ordering.
3. **Resolve item 6 by building full-tier support instead of capping** — Wire the upscale-to-full path against the existing `full.yaml` (plus any missing full-specific artifact templates) so the advisory becomes honest rather than suppressed. Tradeoff: large scope for a tier no change has yet needed, and it delays the five mechanical fixes if coupled to them.
