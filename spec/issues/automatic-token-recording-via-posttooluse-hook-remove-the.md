# Automatic token recording via PostToolUse hook — remove the human/orchestrator from the loop. The shipped token-usage-tracking feature relies on a prose contract: lifecycle skills instruct the orchestrator to run 'metta tokens record' after each subagent returns, which depends on model compliance and records approximate self-reported counts. Make recording automatic framework behavior so the end user just reviews TOKENS.md post-build: add a PostToolUse hook on the Agent/Task tool (deterministic, harness-executed, like metta-guard-bash) that extracts the exact subagent token usage from the hook payload and invokes 'metta tokens record' itself. Research needed: exact PostToolUse payload shape for Task-tool completions (whether usage/subagent_tokens is exposed to hooks in the installed Claude Code version); worktree-aware active-change resolution from a hook cwd (the guard-edit hook's worktree-blindness observed 2026-08-08 also blocks this); dedupe strategy so hook-recorded and prose-recorded entries do not double count (then demote or remove the skill-prose instruction; GAPS section becomes a hook-health indicator). Origin: user request following the token-usage-tracking-finalize-report change (archived 2026-08-08).
